## تصمیم اجرایی / Execution decision

اولویت P0 نصب واقعی و پایدار است. قابلیت‌های مشابه فقط پس از گذر این مرحله و با پیاده‌سازی مستقل افزوده می‌شوند. اسکن گستردهٔ سروری، شمارندهٔ نمایشی و «IP تمیز» بدون تست شبکهٔ کاربر پذیرفته نیست.

1. Restore trustworthy installation and field evidence before feature expansion.
2. P1: bulk operations, accurate usage/error bounds and quotas with documented Free row costs.
3. P2: manual endpoint lists and opt-in client tests with provenance, time, network class and bounded retention. Registry contribution must exclude subscriber IPs and all credentials.
4. P3/P4: client-specific DNS, fragment/ECH/routing and subscription conversion; validate each output with its real core. Chain egress must disclose fallback behavior and validate destinations.
5. P5: diagnostics, encrypted export/import, upgrade preservation and bilingual guides/screenshots. Never label experimental features stable.

The comparison is incomplete for code-level security, real competitor deployments, precise client-version support and one unresolved repository. These are explicitly pending, not assumed safe or compatible with Free.
