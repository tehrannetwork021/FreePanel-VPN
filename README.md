<p align="center">Bilingual Persian/English serverless edge panel for Cloudflare Workers — no VPS, local-first setup, graphical dashboard.</p>

## فارسی
این پروژه یک پنل مستقل Tehran Network است. هدف V1 این است که کاربر در Installer فقط یک Cloudflare Scoped API Token وارد کند و ساخت Worker/KV/Binding به‌صورت خودکار انجام شود. Token نباید ذخیره شود.

### بخش‌های محصول
Dashboard، Protocols، Smart Endpoints، Subscriptions، Routing & Outbound، DNS & ECH، Network Lab، Logs، Backup، Security و Settings.

## English
Tehran Network Edge Panel is a clean, modular serverless control panel for Cloudflare Workers. V1 targets one-token local-first provisioning without requiring a personal VPS.

> Development status: Foundation milestone in progress. Demo data will always be explicitly labeled and will never be presented as production telemetry.
